## Định nghĩa (SAP)

ABAP source code có thể được **enhance mà không sửa code gốc**, trong đó có **BAdIs**, thuộc **ABAP Enhancement Framework**.

Các tùy chọn enhancement khác: xem *Enhancement Framework* trên SAP Help Portal.

## Liên quan thao tác SE19

- **Enhancement spot** — chứa BAdI definition (ví dụ `ES_FINS_ACDOCA`)
- **Enhancement implementation** — object Z* quản trị implementation của bạn
