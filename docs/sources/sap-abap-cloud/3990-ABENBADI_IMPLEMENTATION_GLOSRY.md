# BAdI implementation

*Source:* [https://help.sap.com/doc/abapdocu_cp_index_htm/CLOUD/en-US/ABENBADI_IMPLEMENTATION_GLOSRY.html](https://help.sap.com/doc/abapdocu_cp_index_htm/CLOUD/en-US/ABENBADI_IMPLEMENTATION_GLOSRY.html)

Implementation of a BAdI. Multiple BAdI implementations can be assigned to a single BAdI. A BAdI implementation consists of a BAdI implementation class and a filter condition that can be used to select the BAdI implementation in the `GET BADI` statement in the BAdI object. A BAdI implementation can be in the state *active* or *inactive*, which overrides both the Switch Framework setting and the filter condition.
