# enhancement spot

*Source:* [https://help.sap.com/doc/abapdocu_cp_index_htm/CLOUD/en-US/ABENENHANCEMENT_SPOT_GLOSRY.html](https://help.sap.com/doc/abapdocu_cp_index_htm/CLOUD/en-US/ABENENHANCEMENT_SPOT_GLOSRY.html)

A repository object used for the administration of explicitly created enhancement options. Enhancement spots are components of a tree structure hierarchy, whose branches represent composite enhancement spots and whose leaves are simple enhancement spots. Enhancement points that are available implicitly do not have enhancement spots.
