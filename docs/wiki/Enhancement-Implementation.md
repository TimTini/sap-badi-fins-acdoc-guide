## Định nghĩa (SAP)

Repository object dùng để **quản trị enhancements** của repository objects khác.

Cấu trúc phân cấp:

- **Nhánh** — composite enhancement implementations
- **Lá** — simple enhancement implementations

## Trong SE19 (New BAdI)

1. Chọn Enhancement Spot (ví dụ `ES_FINS_ACDOCA`)
2. Tạo **enhancement implementation** (ví dụ `ZEI_*`)
3. Bên trong, tạo **BAdI implementation** cho từng BAdI definition
