0. Cơ bản: BAdI là gì?

BAdI là gì?

BAdI là viết tắt của Business Add-In. Trong ABAP Keyword Documentation, BAdI là template cho BAdI object, gồm BAdI interface, filters và các setting liên quan. [S1]

BAdI cho phép implement enhancement cho ứng dụng SAP standard mà không sửa original code của SAP. [S2]

Trong ABAP enhancement concept, BAdI và điểm gọi của nó trong chương trình ABAP tạo thành explicit enhancement options và được gán vào enhancement spots. [S3]

Enhance BAdI là gì?

Với New BAdI, khi tạo implementation trong Enhancement Framework, bạn quản trị nó thông qua enhancement implementation. [S4]

Sau đó tạo BAdI implementation và gắn vào BAdI definition tương ứng trong spot. [S4]

Trong SE19, thao tác thường gặp là chọn New BAdI, nhập Enhancement Spot, rồi tạo enhancement implementation. [S5]

Implementation Class là gì?

ABAP Keyword Documentation nói BAdI chủ yếu gồm BAdI implementation class, và instance của class này enhance function của ABAP program tại runtime như một object plug-in. [S3]

ABAP Glossary: BAdI implementation classes là thành phần chính của BAdI implementations; instance hoạt động như object plug-ins. [S6]

Kết luận: code ABAP viết trong implementation class; interface BAdI chỉ khai báo method. [S3]

2. Tạo BAdI Implementation

Mục tiêu

Tạo đủ 3 object customer:

ZEI_FINS_ACDOCA
ZBI_FINS_ACDOC_FCAT
ZCL_IM_FINS_ACDOC_FCAT

Các bước

  1. Vào transaction SE19.
  2. Chọn tạo implementation cho New BAdI hoặc theo Enhancement Spot.
  3. Nhập enhancement spot: ES_FINS_ACDOCA.
  4. Tạo Enhancement Implementation, ví dụ: ZEI_FINS_ACDOCA.
  5. Trong Enhancement Implementation, tạo BAdI Implementation cho BADI_FINS_ACDOC_FIELDCAT.
  6. Đặt tên BAdI Implementation, ví dụ: ZBI_FINS_ACDOC_FCAT.
  7. Tạo hoặc để SAP sinh Implementation Class, ví dụ: ZCL_IM_FINS_ACDOC_FCAT.
  8. Code trong class ZCL_IM_FINS_ACDOC_FCAT — không code trong interface IF_BADI_FINS_ACDOC_FIELDCAT.

Method thường dùng

CHANGE_ACTIVE_FIELDS_BCF_OI — Open item / ACDOCA blank CHANGE_ACTIVE_FIELDS_BCF_BS — Balance Sheet CHANGE_ACTIVE_FIELDS_BCF_PL — P&L

Code mẫu

Thay ZZBRANCH bằng technical field name thật trong ACDOCA. Trước khi code: mở SE24 để xác nhận đúng tên CHANGING parameter trong hệ thống của bạn. 
METHOD if_badi_fins_acdoc_fieldcat~change_active_fields_bcf_oi.

  CONSTANTS lc_field TYPE fieldname VALUE 'ZZBRANCH'.

  IF NOT line_exists( ct_active_fields[ fieldname = lc_field ] ).
    APPEND VALUE #( fieldname = lc_field ) TO ct_active_fields.
  ENDIF.

ENDMETHOD.

Nếu hệ thống không có parameter ct_active_fields:

SE24 → IF_BADI_FINS_ACDOC_FIELDCAT → method cần xem → Parameters

Kiểm tra tên CHANGING parameter thật và sửa code theo signature thực tế.

3. Disable / Deactivate

Khi nào dùng?

Tắt ảnh hưởng runtime nhưng vẫn giữ object để sửa tiếp hoặc rollback.

Các bước (ưu tiên)

  1. Vào SE19, mở Enhancement Implementation ZEI_FINS_ACDOCA.
  2. Change mode → node BAdI Implementation ZBI_FINS_ACDOC_FCAT.
  3. Deactivate implementation hoặc tắt active flag (BAdI implementation có trạng thái active/inactive). [S5]
  4. Save và Activate lại object nếu hệ thống yêu cầu.
  5. Test lại Balance Carryforward: FAGLGVTR hoặc app Carry Forward Balances.

Cách disable bằng code (fallback)

Chỉ dùng khi không thấy nút deactivate rõ ràng — BAdI vẫn được gọi, chỉ không còn tác động logic:

METHOD if_badi_fins_acdoc_fieldcat~change_active_fields_bcf_oi.

  "* Disabled: không append custom field nữa
  "* APPEND VALUE #( fieldname = 'ZZBRANCH' ) TO ct_active_fields.

ENDMETHOD.

4. Xóa implementation

Thứ tự xóa khuyến nghị

  1. Deactivate trước.
  2. Test lại.
  3. Xóa BAdI Implementation ZBI_* nếu còn.
  4. Xóa Enhancement Implementation ZEI_*.
  5. Xóa Implementation Class ZCL_* nếu không còn reference.
  6. Activate và transport nếu cần.

Không xóa SAP standard object

ES_FINS_ACDOCA
BADI_FINS_ACDOC_FIELDCAT
IF_BADI_FINS_ACDOC_FIELDCAT

Kiểm tra còn sót ZBI_*

CáchThao tác
SE19Thử mở ZBI_FINS_ACDOC_FCAT — không tồn tại = đã xóa hoặc xóa theo parent.
SE80Package / $TMP → Enhancements → Enhancement Implementations.
SE84Enhancements → BAdI Implementations → search ZBI_FINS_ACDOC_FCAT.

Nếu đã xóa ZEI_FINS_ACDOCA trước, ZBI_FINS_ACDOC_FCAT thường bị xóa theo — vẫn nên kiểm tra lại bằng SE19 / SE80 / SE84.

6. Checklist cuối

Tạo

  • Đúng Enhancement Spot: ES_FINS_ACDOCA
  • Có Enhancement Implementation: ZEI_*
  • Có BAdI Implementation: ZBI_*
  • Có Implementation Class: ZCL_*
  • Code nằm trong class, không trong interface
  • Đúng method: BCF_OI, BCF_BS, hoặc BCF_PL

Disable

  • Deactivate trước khi xóa
  • Test lại BCF
  • Không để object inactive ngoài ý muốn
  • Có transport nếu cần đưa lên QA/PRD

Xóa

  • Không xóa SAP standard object
  • Check ZBI_* còn không
  • Check class còn reference không
  • Check bằng SE19, SE80, SE84
  • Activate và transport
